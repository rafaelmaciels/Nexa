Guia de Instalação Oficial

Como Instalar o Nexa no Windows 11 / Windows 10 (x64)

Este manual passo a passo ensina como obter o executável, configurar as regras necessárias no Windows Firewall e executar o daemon com suporte a janelas administrativas (UAC).

Requisitos do Sistema

  • Sistema Operacional: Windows 11 (todas as edições) ou Windows 10 x64 (versão 1809 ou superior).
  • Permissões: Acesso de administrador local (para abrir a porta do firewall).
  • Rede: Conectado à mesma rede local (Wi-Fi 2.4/5GHz ou cabo Ethernet) que os demais computadores.

Passo 1: Baixar e Extrair o Pacote Portátil

Baixe o pacote oficial compactado diretamente dos releases do GitHub e extraia os arquivos em uma pasta de sua escolha (recomendado: C:\Nexa\):

https://github.com/rafaelmaciels/Nexa/releases/latest/download/nexa-windows-x64.zip Download ZIP

Passo 2: Liberar a Porta 25800 no Firewall do Windows

Para permitir que outros computadores da rede alcancem o Nexa, abra o PowerShell como Administrador e execute o comando:

PowerShell (Administrador) 
netsh advfirewall firewall add rule name="Nexa KVM Share" dir=in action=allow protocol=TCP localport=25800 profile=any

Passo 3: Iniciar o Nexa em Modo Servidor (Host)

Se este computador tem o teclado e o mouse físicos conectados:

Terminal 
.\nexa-daemon.exe --server --port 25800

Ou simplesmente dê um duplo clique no executável nexa-daemon.exe para abrir a interface gráfica automaticamente no seu navegador padrão em http://127.0.0.1:25802.

Passo 4: Configurar Inicialização com Permissões Elevadas (UAC)

No Windows, programas comuns deixam de capturar teclas e cliques quando uma janela do Gerenciador de Tarefas ou tela de consentimento UAC é aberta. O Nexa resolve isso configurando uma tarefa agendada no logon com privilégios máximos:

.\nexa-daemon.exe --autostart-enable
