Como Instalar o Nexa no Linux (Wayland e X11)

Guia completo para distribuições baseadas em Debian e Ubuntu, incluindo o elementary OS 8.1 (Gala / Wayland).

Passo 1: Instalar o Pacote Oficial (.deb)

Baixe o pacote compilado para a arquitetura x86_64 e instale pelo terminal:

Terminal Bash 
wget https://github.com/rafaelmaciels/Nexa/releases/latest/download/nexa_0.1.0_amd64.deb
sudo dpkg -i nexa_0.1.0_amd64.deb
sudo apt-get install -f

Passo 2: Configurar o Emulador do Kernel (/dev/uinput)

Para que o Nexa injete eventos de teclado e movimentação de mouse sem precisar rodar como superusuário (root), configure as permissões do dispositivo uinput:

sudo modprobe uinput && sudo chmod 666 /dev/uinput && sudo usermod -aG input $USER

Regra persistente udev para que a configuração sobreviva a reinicializações:

Regra Udev Permanente 
echo 'KERNEL=="uinput", SUBSYSTEM=="misc", TAG+="uaccess", OPTIONS+="static_node=uinput", MODE="0666"' | sudo tee /etc/udev/rules.d/99-nexa-uinput.rules
sudo udevadm control --reload-rules
sudo udevadm trigger

Passo 3: Liberar o Firewall UFW

Se você utiliza o UFW (padrão no Ubuntu e elementary OS), libere a porta oficial:

sudo ufw allow 25800/tcp comment "Nexa KVM Share"

Passo 4: Conectar ao Computador Windows

Inicie o cliente informando o IP do computador Host (onde o mouse físico está conectado):

Terminal 
nexa-daemon --client 192.168.1.15:25800
🔐
Confirmação de Segurança (PIN SAS): Na primeira conexão, um código de 6 dígitos (ex: 482 731) será exibido nos dois computadores. Olhe para os dois monitores e certifique-se de que os números coincidem para evitar ataques de homem-no-meio.

Passo 5: Rodar como Serviço de Usuário (systemd --user)

Para que o Nexa inicie automaticamente junto com a sua sessão gráfica do usuário:

systemctl --user enable --now nexa.service
