🐧 Solução Definitiva para o Linux (/dev/uinput)
No Linux, o sistema operacional exige permissão de acesso ao driver do kernel /dev/uinput para mover o mouse e digitar sem necessidade de sudo.
Execute este comando único no terminal do Linux para configurar e liberar o mouse instantaneamente:
sudo modprobe uinput && sudo chmod 666 /dev/uinput && sudo usermod -aG input $USER
