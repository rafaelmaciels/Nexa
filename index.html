🐧 Solução Definitiva para o Linux (/dev/uinput)
No Linux, o sistema operacional exige permissão de acesso ao driver do kernel /dev/uinput para mover o mouse e digitar sem necessidade de root. Execute este comando único no terminal para liberar o acesso instantaneamente:
sudo modprobe uinput && sudo chmod 666 /dev/uinput && sudo usermod -aG input $USER
Engenharia Moderna

Construído para superar as limitações do passado

Softwares tradicionais de KVM sofrem com bases de código antigas em C++, latência perceptível, falhas de segurança e problemas com compositores modernos. O Nexa foi projetado do zero em Rust para uma experiência sem fricção.

Criptografia Ponta a Ponta

Toda a movimentação de mouse, teclas e textos trafegam por canal cifrado com ChaCha20-Poly1305. Um código visual SAS PIN de 6 dígitos confirma o pareamento e elimina ataques de Homem-no-Meio (MITM).

Zero Sniffing

Coalescência de Mouse Gamer

Mouses de alta taxa de polling (500 Hz a 1000 Hz) geram milhares de eventos por segundo. O coalescedor adaptativo do Nexa compacta pacotes em janelas de 3ms, cortando o uso de banda em 75% sem qualquer perda de precisão.

Taxa 1000 Hz Nativa

Clipboard com Algoritmo Anti-Echo

Copie textos formatados, códigos e emojis em uma máquina e cole na outra. O algoritmo de hash SHA-256 previne ativamente loops infinitos de cópia e conta com barreira protetora contra payloads gigantescos de até 10 MB.

UTF-8 Completo

Independência de Bandas Wi-Fi

Conecte suas máquinas mesmo se uma estiver no Wi-Fi 2.4 GHz e a outra no 5.0 GHz ou no cabo de rede Ethernet. O Nexa opera via TCP direto com fallback para descoberta automática por broadcast UDP local.

TCP + UDP Broadcast

Topologia Espacial 2D

Converte resoluções assimétricas (ex.: monitor 4K 3840x2160 no Windows ao lado de tela Full HD 1920x1080 no Linux) através de coordenadas normalizadas (0..65535), garantindo que o cursor entre exatamente na altura certa.

Por dentro do motor

Arquitetura de Baixo Nível e Protocolo Binário

Veja como o Nexa orquestra hooks do sistema operacional, criptografia e serialização binária com overhead mínimo.

1
Captura Nativa de Entrada
No Windows, o Nexa instala Low-Level Hooks (WH_MOUSE_LL e WH_KEYBOARD_LL) com DPI Awareness ativo. No Linux, emula os periféricos diretamente no kernel via /dev/uinput.
2
Framing Binário de 16 Bytes
Todo pacote possui cabeçalho de 16 bytes: Magic 0x4E455841 ("NEXA"), versão, tipo de evento (mouse, teclado, clipboard, ping/pong), tamanho do payload e checksum CRC32 anti-corrupção.
3
Túnel Criptográfico Seguro
O handshake troca chaves efêmeras X25519 e deriva uma chave simétrica de 32 bytes via HKDF-SHA256. Nonces sequenciais garantem rejeição imediata de ataques de repetição (anti-replay).
4
Injeção Transparente no SO
Quando o cursor cruza a borda, o Nexa suprime os eventos na máquina transmissora e transmite as coordenadas normalizadas para o receptor, que injeta os scancodes exatos (ABNT2 e US).

Instalação e Configuração Rápida

Escolha o sistema operacional correspondente e configure sua rede local em poucos passos.

1
Download do Executável

Baixe o pacote pré-compilado para Windows x64 e extraia em C:\Nexa\:

https://github.com/rafaelmaciels/Nexa/releases/latest/download/nexa-windows-x64.zip Download (.zip)
2
Liberar a Porta 25800 no Firewall do Windows

Abra o PowerShell como Administrador e execute:

netsh advfirewall firewall add rule name="Nexa KVM Share" dir=in action=allow protocol=TCP localport=25800 profile=any
3
Iniciar o Painel Gráfico ou Linha de Comando

Dê um duplo clique em nexa-daemon.exe para abrir a interface gráfica no navegador ou inicie via terminal:

.\nexa-daemon.exe --server --port 25800
1
Download e Instalação do Pacote .deb

Baixe o pacote oficial e instale via terminal:

wget https://github.com/rafaelmaciels/Nexa/releases/latest/download/nexa_0.1.0_amd64.deb && sudo dpkg -i nexa_0.1.0_amd64.deb
2
Permissões de Emulação (/dev/uinput) e Firewall

Permita que o usuário manipule o mouse e libere a porta no UFW:

sudo modprobe uinput && sudo chmod 666 /dev/uinput && sudo usermod -aG input $USER && sudo ufw allow 25800/tcp
3
Conectar ao Computador Host (Windows)

Inicie o cliente apontando para o IP do seu computador principal:

nexa-daemon --client 192.168.1.15:25800

* Na primeira conexão, confirme o código numérico SAS de 6 dígitos que surgirá nas duas telas para autenticar com segurança.
