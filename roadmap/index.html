Estado Real do Projeto & Roadmap Oficial

O Nexa é desenvolvido publicamente em código aberto. Esta matriz detalha com honestidade o que já está testado e em produção, o que está em desenvolvimento ativo e o que é planejado para as próximas versões.

Modo Principal
Windows ➔ Linux

Controle de Linux pelo Windows operacional com /dev/uinput.

Em Desenvolvimento
Wayland Portal Host

XDG Desktop Portal e libeis para Linux como transmissor.

Recurso / Plataforma Classificação Comportamento Técnico no Código
Windows como Host (Transmissor) Implementado Hooks de baixo nível (WH_MOUSE_LL, WH_KEYBOARD_LL) com supressão e DPI awareness.
Windows como Guest (Receptor) Implementado Injeção via SendInput com scancodes estendidos ABNT2 e US.
Linux como Guest (Receptor) Implementado Driver virtual de kernel /dev/uinput via ioctl sem necessidade de root.
Linux como Host (Transmissor Wayland) Em Desenvolvimento Estrutura LinuxInputCapturer criada; integração com portal XDG em progresso.
Criptografia ChaCha20-Poly1305 Implementado Canal autenticado de ponta a ponta com nonces incrementais anti-replay.
Confirmação Visual SAS PIN Implementado Derivação HKDF-SHA256 gerando código numérico XXX YYY contra ataques MITM.
Clipboard Anti-Echo SHA-256 Implementado Supressão ativa de loops de cópia e limite protetor de 10 MB contra travamentos.
Coalescência de Mouse Gamer Implementado Compactação em janelas de 3ms mantendo fidelidade de mouses de 1000Hz.
Transferência de Arquivos Drag & Drop Planejado Streaming de arquivos entre computadores arrastando itens pela borda do monitor.
Suporte a macOS (Apple Silicon & Intel) Planejado Implementação de capturador e injetor nativos via CGEventTap e Quartz.
